1. VARIABLES Y OPERACIONES
   ======================================================================

ESTADO: CUMPLIDO

El proyecto utiliza variables y operaciones propias de Python y Django.

Ejemplos:

* Variables recibidas desde solicitudes HTTP.
* Identificadores de eventos.
* Variables utilizadas para almacenar eventos.
* Variables utilizadas para encuestas.
* Variables utilizadas para votos.
* Variables utilizadas para calcular porcentajes.
* Operaciones aritméticas.
* Operaciones de comparación.
* Conversión y manipulación de datos.

En la vista de resultados se utiliza una operación matemática para
calcular el porcentaje de cada alternativa:

porcentaje = (votos de la alternativa / total de votos) * 100

El resultado se redondea a dos decimales.

También se controla el caso en que total_votes sea igual a cero para
evitar una división por cero.

7. MODELOS DJANGO
=================

ESTADO: CUMPLIDO

Se implementaron modelos utilizando Django ORM.

MODELO EVENT:

Campos:

* name
* description
* date
* location
* price
* capacity
* image

MODELO POLL:

Campos:

* event
* question

MODELO CHOICE:

Campos:

* poll
* choice_text
* votes

Relaciones:

Event 1 ---- 1 Poll

Poll 1 ---- N Choice

El modelo Event utiliza DecimalField para el precio y ImageField para
las imágenes.

El modelo Choice utiliza un campo votes para almacenar la cantidad de
votos recibidos.

Se generaron y aplicaron las migraciones correspondientes.
